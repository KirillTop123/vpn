# VPN-сервис под ключ: панель + Telegram-бот + ноды для Happ

Готовый продукт для продажи VPN-подписок:

- **Протоколы, которые сейчас лучше всего проходят ТСПУ/DPI:** VLESS + Reality + Vision (TCP) и
  VLESS + Reality + XHTTP. Для каждого сервера клиент получает оба варианта: если один режут, работает другой.
- **Режим «белых списков».** Нода-«мост» ставится в российском облаке, чьи IP-адреса входят в белые списки
  мобильных операторов. Она маскируется под разрешённый сайт (SNI), принимает пользователей и пересылает трафик
  на зарубежный сервер. Российские сайты при этом открываются напрямую из РФ.
- **Сколько угодно серверов.** Новый сервер добавляется одной командой и сразу появляется у всех клиентов.
  Упавшие серверы автоматически убираются из подписки.
- **Happ** (iOS, Android, Windows, macOS): подписка добавляется одной кнопкой. Внутри приложения видны название
  бренда, срок действия, израсходованный трафик, кнопка поддержки и объявление.
- **Telegram-бот для продаж:** пробный период, оплата звёздами Telegram ⭐ (не нужны ИП и эквайринг),
  реферальная программа, напоминания об окончании подписки, рассылки.
- **Веб-админка:** пользователи, серверы, платежи, выручка, трафик.

```
                    ┌──────────── Панель (Docker) ────────────┐
  Happ ──подписка──▶│  FastAPI  ·  админка  ·  Telegram-бот   │
                    └──────▲──────────────────────────▲───────┘
                 конфиг/статистика              конфиг/статистика
                           │                          │
   Happ ══VLESS Reality══▶ Нода-мост (РФ, белый IP) ══▶ Нода-выход (NL/DE/FI…) ══▶ Интернет
   Happ ═════════════════VLESS Reality══════════════▶ Нода-выход
```

## 🚀 Бесплатный запуск за 15 минут (всё на одном сервере)

Панель, бот и VPN встают на одну бесплатную машину Oracle Cloud командой из одной строки. Домен не нужен.

**Шаг 1. Бот (2 минуты).** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и получите
**токен**. Свой **Telegram ID** узнайте у [@userinfobot](https://t.me/userinfobot).

**Шаг 2. Бесплатный сервер (10 минут).**
1. Зарегистрируйтесь на [cloud.oracle.com](https://signup.cloud.oracle.com) (тариф *Always Free*). Карта нужна только
   для проверки, деньги не списываются. Регион выбирайте европейский (Frankfurt, Amsterdam, Stockholm): сменить
   его потом нельзя.
2. *Compute → Instances → Create instance*:
   - Image: **Ubuntu 22.04** или 24.04;
   - Shape: **VM.Standard.A1.Flex** (ARM, бесплатно до 4 CPU / 24 ГБ). Если пишет «Out of capacity», возьмите
     **VM.Standard.E2.1.Micro** или попробуйте позже;
   - скачайте SSH-ключ (*Save private key*).
3. Откройте порты: *Networking → Virtual cloud networks → ваша сеть → Security Lists → Default → Add Ingress Rules*:
   Source `0.0.0.0/0`, TCP, Destination ports `80,443,8443,2096`.

**Шаг 3. Одна команда.** Подключитесь к серверу (`ssh -i ключ.key ubuntu@IP`, на Windows то же самое в PowerShell)
и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/KirillTop123/vpn/claude/vpn-service/deploy/oneclick.sh | sudo bash -s -- ТОКЕН_БОТА ВАШ_TELEGRAM_ID "Название VPN"
```

Через 3–5 минут скрипт напечатает адрес админки, пароль и ссылку на бота (они же сохранятся в
`/root/vpn-credentials.txt`). После этого всё работает **автономно**:

- бот, панель и VPN перезапускаются сами после сбоя или перезагрузки сервера;
- HTTPS-сертификат продлевается автоматически, гео-базы обновляются еженедельно, Ubuntu ставит обновления
  безопасности;
- каждый день бот присылает вам в Telegram бэкап базы;
- пользователи сами берут пробный период, сами платят звёздами и сами продлевают подписку.

Чтобы добавить ещё серверы, достаточно второго бесплатного аккаунта Oracle (у друга или родственника) или любого
VPS: в админке «Серверы» → «Добавить» → выполнить команду на сервере.

> ⚠️ **Белые списки бесплатно не обойти.** Зарубежный сервер Oracle работает при обычных блокировках и замедлениях,
> но при режиме белых списков на мобильном интернете нужен «мост» в российском облаке (раздел 3 ниже). Бесплатных
> российских облаков нет. У Яндекс Облака есть стартовый грант на 60 дней, его хватит, чтобы проверить схему,
> дальше это ~500–1500 ₽/мес.

## Сколько это стоит

Весь софт бесплатный и open-source (Xray, этот код, Happ). **Платить нужно только за серверы**, тут бесплатно не
бывает:

| Что | Где | Цена |
|---|---|---|
| Панель | любой VPS (можно на той же машине, что и нода) | от ~300 ₽/мес |
| Нода-выход | Hetzner, Aeza, PQ.Hosting, Timeweb (зарубежные локации) и т.п. | ~300–600 ₽/мес за сервер |
| Нода-мост для белых списков | облако из белого списка (Яндекс Облако, VK Cloud, Selectel и т.п.) | ~500–1500 ₽/мес |
| Бесплатный вариант для старта | Oracle Cloud Always Free (2 ВМ навсегда) | 0 ₽ |
| Домен для панели | любой регистратор | от ~200 ₽/год |

Тарифы по умолчанию (меняются в `.env`): 150 ⭐ в месяц ≈ 200–300 ₽. Один сервер за ~500 ₽ спокойно тянет
50–150 пользователей, так что окупается он с 3–5 подписчиков.

## Установка

### 1. Панель

Нужен VPS (Ubuntu 22.04+) и домен, A-запись которого указывает на этот VPS.

```bash
curl -fsSL https://get.docker.com | sh
git clone <этот репозиторий> vpn && cd vpn
cp .env.example .env
nano .env        # домен, пароль админки, SECRET_KEY, BOT_TOKEN, ваш Telegram ID, бренд, цены
docker compose up -d --build
```

Админка будет по адресу `https://ваш-домен/admin`. HTTPS-сертификат Caddy получит автоматически.

> Если панель стоит на той же машине, что и нода, порт 443 будет занят Caddy. В таком случае задайте ноде
> другие порты (например, 2053 и 2083) или вынесите панель на отдельный дешёвый VPS. Второй вариант надёжнее:
> блокировка одного сервера не затронет остальные.

### 2. Серверы (ноды)

1. В админке откройте «Серверы» → «Добавить»: укажите флаг, название, IP и SNI.
2. Откроется страница сервера с командой установки. Выполните её на чистом VPS под root:
   ```bash
   curl -fsSL https://ваш-домен/node/install.sh | sudo bash -s -- https://ваш-домен <токен>
   ```
3. Примерно через 30 секунд сервер станет «онлайн» и появится у всех клиентов.

Скрипт ставит Xray-core, включает BBR, устанавливает агента (systemd-сервис `vpn-agent`) и еженедельно обновляет
geo-базы. Перед применением агент проверяет каждый конфиг через `xray run -test`, поэтому сломать ноду из
панели нельзя.

### 3. Обход белых списков (мобильный интернет)

При режиме белых списков оператор пропускает трафик только к разрешённым IP-адресам и доменам. Зарубежный
сервер в такой ситуации недоступен, поэтому нужна цепочка:

1. Добавьте и установите обычную зарубежную ноду, например «🇳🇱 Нидерланды».
2. Арендуйте ВМ у российского облачного провайдера, чьи подсети попадают в белые списки. Списки меняются и
   отличаются у разных операторов и регионов, так что проверяйте на месте: с мобильного интернета в режиме
   ограничений IP вашей ВМ должен пинговаться и отвечать.
3. Добавьте эту ВМ как ноду: название, например, «🇷🇺 Белые списки», в поле «Мост через» выберите нидерландскую
   ноду, а **SNI укажите домен из белого списка** (например, сайт крупного российского сервиса, который
   отвечает по TLS 1.3). Установите ноду той же командой.

Пользователи увидят в Happ отдельный сервер «Белые списки». Трафик идёт так: телефон → мост в РФ (оператор видит
подключение к разрешённому IP с разрешённым SNI) → зарубежная нода → интернет. Российские сайты мост открывает
напрямую.

### 4. Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) и вставьте токен в `BOT_TOKEN`.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot) и вставьте его в `ADMIN_TG_IDS`.
3. Выполните `docker compose up -d`.

Пользователь нажимает «Попробовать бесплатно», получает ссылку, по кнопке «Подключить в Happ» открывается
страница с кнопкой добавления подписки. Звёзды с продаж копятся на боте, вывести их можно через Fragment в TON
или потратить на рекламу в Telegram.

Команды администратора в боте: `/stats`, `/give <telegram_id> <дней>`, `/broadcast <текст>`.

## Выбор SNI (маскировки)

SNI — это сайт, под который маскируется сервер. Требования: сайт поддерживает TLS 1.3 и HTTP/2, не стоит за
Cloudflare и в идеале размещён у того же хостера или в той же стране, что и ваша нода.

- Зарубежные ноды: `www.microsoft.com`, `www.apple.com`, `dl.google.com`, `www.samsung.com` или сайт в той же
  подсети хостера (чем «ближе», тем лучше).
- Мосты для белых списков: домен из белого списка, доступный по TLS 1.3.

Проверка с ноды: `curl -sI --tlsv1.3 --http2 https://домен | head -1`.

## Советы по продажам

- Держите минимум 2–3 зарубежные локации и 1–2 моста: при блокировке одного сервера клиенты просто
  переключаются на другой. Новый сервер добавляется за 2 минуты и без действий со стороны пользователей.
- Чтобы заблокированная нода не попадала в подписку, выключите её в админке, а затем замените на новый IP.
- Объявление в Happ (`ANNOUNCE`) удобно для новостей вроде «добавили новый сервер в Германии».
- Если ссылка пользователя утекла, нажмите 🔑 в админке: старая ссылка и ключ перестанут работать.

## Разработка

```bash
cd panel
pip install -r requirements.txt pytest httpx
pytest                                   # тесты
ADMIN_PASSWORD=pw uvicorn app.main:app --reload   # панель на http://localhost:8000/admin
BOT_TOKEN=... python -m app.bot          # бот
```

Структура:

```
panel/app/main.py         подписка /sub/<token>, API для нод
panel/app/admin.py        веб-админка
panel/app/bot.py          Telegram-бот (Stars, пробный период, рефералы, напоминания)
panel/app/xray_config.py  генерация конфига Xray для ноды (выход / мост)
panel/app/links.py        vless-ссылки и заголовки подписки для Happ
node/install.sh           установка ноды одной командой
node/agent.py             агент на ноде: синхронизация конфига и статистики
```

## Юридическое

В разных странах VPN регулируется по-разному. В РФ, в частности, запрещена реклама средств обхода блокировок,
а сервисы, не подключённые к реестру Роскомнадзора, могут блокировать. Перед запуском коммерческого сервиса
оцените риски для вашей юрисдикции. Запрещайте в правилах сервиса противоправное использование: в ноде уже
блокируется BitTorrent, это снижает число жалоб абуз-отделов хостеров.
