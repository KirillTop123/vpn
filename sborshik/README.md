# Сборщик баз

Настольное приложение для Windows: ищет компании малого бизнеса в 2ГИС, Яндекс Картах и поиске Яндекса,
собирает их контакты, проверяет сайты и помогает вести переписку (мини-CRM). Все данные лежат в одном
файле SQLite на вашем компьютере.

## Что умеет

- **Новый сбор.** Город + ниша → программа сама подбирает варианты запроса («детейлинг» → «полировка авто»,
  «керамика авто», «оклейка плёнкой»…), по желанию перебирает районы. Проходит выдачу, открывает карточку
  каждой компании и забирает название, рубрики, адрес, район, рейтинг, отзывы, телефоны, сайт, Telegram,
  WhatsApp, MAX, VK, Instagram, e-mail, часы работы, онлайн-запись (YClients, DIKIDI и др.), ссылку на карточку.
- **Обогащение.** Нет сайта в карточке — ищет «название + город» в поиске Яндекса и берёт сайт, только если
  в результате есть и название, и город. Сайт открывает и проверяет: работает ли, SSL, калькулятор, форма
  заявки, онлайн-запись, чат, мобильная версия, год в подвале; забирает со страниц телефоны, почту и
  ссылки t.me / wa.me / vk.com.
- **Дубли** склеиваются по телефону, сайту и названию+адресу. Дилеры и сети помечаются «не мой клиент».
- **База**: таблица и карточки, поиск, сортировка, фильтры, автосегменты с причиной («сайт не открывается»,
  «нет сайта», «нет мессенджеров»…).
- **Воронка** (канбан с перетаскиванием), экран **«Сегодня»** с повторными касаниями, шаблоны сообщений
  с подстановками. Отправки нет: программа только копирует текст и открывает чат.
- **Экспорт** в Excel, CSV, JSON, отдельный «Экспорт для Claude» и **импорт** обратно по ID.

## Скорость и капча

Источники собираются одновременно: у каждого свои окна браузера (по умолчанию 2 на источник, в «Настройках» от 1 до 3),
а сайты компаний проверяются фоном в несколько потоков и окно браузера не занимают. Между страницами в каждом окне
случайная пауза (по умолчанию 2–5 секунд), есть лимит страниц в час на источник. В «Настройках» три готовых режима:
«Осторожно», «Быстро», «Максимум». Чем быстрее темп, тем чаще источник просит капчу.

Если источник показал капчу или ограничил доступ, это окно останавливается и программа пишет:
«Решите капчу в окне браузера и нажмите „Продолжить“». Остальные окна продолжают работать. Капчу программа
не обходит и сама ничего не нажимает.

## Базы, проблемы и сообщения

- **Базы.** Каждый сбор складывает компании в свою базу «ниша, город» (например, «Репетиторы, Уфа»). Экран «База»
  сначала показывает базы-папки, внутри — таблица с фильтрами. Базу можно переименовать и удалить.
- **Проблемы.** У каждой компании ищется всё, что мешает ей получать заявки: сайт не открывается, нет сайта,
  сайт устарел или слишком простой, одностраничник, нет мобильной версии, SSL, формы, калькулятора, цен, мессенджеров,
  счётчика, политики конфиденциальности, примеров работ, телефон не нажимается, медленная загрузка, мало отзывов,
  низкий рейтинг и другое. Самая сильная проблема становится сегментом, остальные видны в карточке и в фильтре
  «Любая проблема».
- **Вид сайта** оценивается по вёрстке и стилям (таблицы и теги 2000-х, шрифты, анимации, фотографии, адаптивность),
  а не по году в подвале. Это эвристика: сайты, которые целиком рисуются скриптами, она не оценивает.
- **Перепроверить сайты** — кнопка в базе: заново проверяет сайты уже собранных компаний, браузер для этого не нужен.
- **Сообщения.** Шаблон «Умное первое сообщение» собирается под компанию: `{представление}` (ваше имя из «Настроек»
  и чем вы занимаетесь — задаётся в базе), `{зацепка}` (похвала отзывам, только если их действительно много),
  `{проблема}` и `{предложение}` (подбираются под главную проблему). Фразы лежат в `data\pitches.json` и редактируются.

## Установка и запуск

Нужен Windows 10/11 и [Python 3.11+](https://www.python.org/downloads/) (при установке отметьте
«Add python.exe to PATH»).

**Проще всего:** дважды щёлкните `run.bat`. При первом запуске он создаст окружение, поставит зависимости
и браузер Chromium, затем откроет окно программы.

Вручную:

```bat
cd sborshik
py -3 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m playwright install chromium
.venv\Scripts\python app.py
```

Chromium ставить необязательно: в «Настройках» можно выбрать Microsoft Edge или Google Chrome,
а в режиме «Автовыбор» программа сама возьмёт установленный браузер.

Запуск без окна (интерфейс откроется в обычном браузере): `python app.py --no-window`.

## Сборка в один .exe

Запустите `build.bat` — готовый файл появится в `dist\SborshikBaz.exe`. Вручную:

```bat
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller --noconfirm --clean --onefile --windowed --name SborshikBaz ^
  --add-data "ui;ui" --add-data "data;data" ^
  --collect-all playwright --collect-submodules uvicorn --collect-submodules webview app.py
```

Браузер в .exe не вшивается (он весит сотни мегабайт). На компьютере, где запускается .exe, должен быть
Edge (есть в Windows по умолчанию), Chrome или Chromium из Playwright.

Без установки Python .exe можно собрать на GitHub: вкладка **Actions → «Сборщик баз: сборка .exe» →
Run workflow**, готовый файл будет в артефактах запуска.

## Где лежат данные

| Что | Где |
|---|---|
| База `sborshik.db`, папки `exports` и `backups` | `%APPDATA%\SborshikBaz` (папку базы можно сменить в «Настройках») |
| Журнал `sborshik.log` | `%APPDATA%\SborshikBaz` |
| Профили окон браузера (чтобы капча и cookies не спрашивались заново) | `%APPDATA%\SborshikBaz\browser-profile-…` |

Резервная копия базы — одна кнопка в «Настройках».

Если программу закрыть во время сбора, прогресс сохранится: при следующем запуске на экране «Новый сбор»
появится кнопка «Продолжить сбор». Уже открытые карточки заново не открываются.

## Как починить селекторы, если источник поменял вёрстку

Признаки: в журнале «на странице не найдено название компании», сбор находит 0 карточек или поля приходят
пустыми.

1. Скопируйте `data\selectors.json` в `%APPDATA%\SborshikBaz\selectors.json`. Программа берёт файл из
   этой папки, если он там есть, — пересобирать .exe не нужно. Оба пути показаны в «Настройках».
2. Откройте сайт источника в Chrome, нажмите F12, выберите стрелкой нужный элемент (название, адрес,
   телефон) и посмотрите его класс или атрибут.
3. Поправьте селектор в файле. В каждом списке селекторы пробуются по порядку, берётся первый сработавший,
   поэтому новый можно дописать в начало, не удаляя старый.
4. Запустите сбор заново (перезапускать программу не нужно: файл читается при каждом обращении).

Что есть в файле для каждого источника:

| Ключ | Назначение |
|---|---|
| `search_url`, `card_url` | шаблоны адресов выдачи и карточки |
| `card_link`, `card_id_regex` | как найти ссылки на карточки в выдаче и достать из них id |
| `card.name`, `address`, `rubrics`, `rating`, `reviews`, `hours`, `site` | поля карточки |
| `card.reveal_phone`, `card.phone_text` | кнопка «показать телефон» и элемент с номером |
| `card.contacts_scope` | блок, внутри которого ищутся ссылки tel:, mailto:, t.me, wa.me, vk.com |
| `captcha_url`, `captcha_selectors`, `blocked_text` | признаки капчи и блокировки |
| `list_scroll`, `list_end` (Яндекс Карты) | прокручиваемый список и признак его конца |
| `state_var` (2ГИС) | переменная с данными страницы; из неё контакты берутся надёжнее, чем из вёрстки |

Телефоны, почта и мессенджеры находятся по самим ссылкам (`tel:`, `mailto:`, `t.me`…), так что обычно
чинить приходится только `name`, `address`, `rating` и `reviews`.

Словари тоже редактируются: `data\synonyms.json` (синонимы ниш), `data\cities.json` (города и районы) и
`data\pitches.json` (фразы для сообщений).
Их так же можно положить в `%APPDATA%\SborshikBaz`.

## Устройство кода

```
app.py                 запуск сервера и окна (pywebview)
api.py                 FastAPI: всё, что вызывает интерфейс
collector.py           движок сбора: окна браузера, очередь, паузы, капча, возобновление, перепроверка сайтов
browser.py             окно Chromium (Playwright), у каждого окна свой профиль
sources/twogis.py      2ГИС
sources/yandex_maps.py Яндекс Карты
sources/yandex_search.py поиск Яндекса (источник сайтов и поиск сайта по названию)
sources/base.py        разбор карточки по селекторам, проверка капчи
enrich/site_check.py   проверка сайта и сбор контактов с него
db.py                  SQLite, склейка дублей, статусы, шаблоны
segments.py            поиск проблем, сегменты, «не мой клиент», сборка сообщений
exporter.py            экспорт и импорт
variants.py            синонимы ниш и районы
data/                  selectors.json, synonyms.json, cities.json, pitches.json
ui/                    интерфейс (HTML, CSS, JS без сборки)
tests/                 тесты; сбор проверяется на локальных макетах сайтов
```

Тесты: `pip install pytest`, затем `pytest tests`. Они не обращаются к настоящим сайтам.

## Важно

Собирайте только открытые контакты организаций и соблюдайте правила сайтов-источников и закон о
персональных данных. Массовой рассылки в программе нет намеренно.
